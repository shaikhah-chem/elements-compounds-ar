# العناصر والمركبات – تجربة الواقع المعزز

تجربة واقع معزز حقيقية: الطالبة توجّه كاميرا الجوال إلى بطاقة مطبوعة فيظهر الجزيء ثلاثي الأبعاد فوقها، ثم تصنّفه (عنصر / مركب)، وتجرب التحليل الكهربائي للماء وبلورة ملح الطعام.

## النشر على GitHub Pages
1. أنشئي مستودعاً جديداً باسم **elements-compounds-ar** في حسابك `shaikhah-chem` (نفس الاسم حتى يعمل رمز QR في العرض).
2. ارفعي **محتويات** هذا المجلد كما هي (index.html و viewer.html والمجلدات css و js و fonts و vendor و targets و cards).
3. Settings ← Pages ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يعمل الرابط: `https://shaikhah-chem.github.io/elements-compounds-ar/`

## الطباعة
- `cards/cards-print.pdf` : البطاقات الأربع في صفحة A4 واحدة — اطبعيها ملونة (يفضّل ورق مقوّى) لكل مجموعة.

## ملاحظات للحصة
- يحتاج جوال المجموعة إلى إنترنت (بيانات الجوال) عند فتح الرابط فقط.
- إن لم تتوفر كاميرا: `viewer.html` يعرض الجزيئات ثلاثية الأبعاد والأسئلة بدون بطاقات.
- ⚠ إذا عدّلتِ صور البطاقات يجب إعادة توليد الملف `targets/cards.mind`.
